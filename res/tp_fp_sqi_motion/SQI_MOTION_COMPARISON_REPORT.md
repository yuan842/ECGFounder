# SQI & Motion Comparison: TP (fzark) vs FP (doctor-removed)

**TP Dataset**: `ecg_tp_fzark` — clinician-confirmed true positives
**FP Dataset**: `ecg_fp_doctor removed1` — clinician-removed false positives
**Sampling**: up to 300 records per event type per dataset (random_state=42)
**TP records extracted**: 2688
**FP records extracted**: 3941

**Interpretation**: FP events are noise the model fires on incorrectly; 
TP events are real arrhythmias. Differences in SQI/motion help explain 
*why* the model makes mistakes and guide suppressor design.
