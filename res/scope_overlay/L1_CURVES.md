# L1 per-head curves — F1-vs-threshold and Precision-Recall

Figures: [l1_curves_leadII.png](l1_curves_leadII.png) · [l1_curves_fuzzy.png](l1_curves_fuzzy.png). Generated by [scripts/plot_l1_curves.py](../../scripts/plot_l1_curves.py). Production L1 heads {4 Brady, 5 AFib, 6 Sinus-Tachy}, PTB-XL fold-10 test.

## What each panel shows

**Left — F1 / Sens / Spec vs threshold.** Blue = F1, green-dashed = Sens, red-dotted = Spec. The **black line + dot = τ\*** (the policy operating point: argmax-F1 with the F1 value annotated). Orange dashed = the default 0.5. The **red-shaded band = the forbidden region** where Sens drops below the floor (`base_sens − 5pp`); the policy picks the F1 peak to the *left* of that band.

**Right — Precision-Recall curve.** Blue = the full PR curve (AP = PR-AUC, the whole-curve area). The **black dot = τ\*** operating point; the **orange square = the τ=0.50** point. This is the visual answer to "is the F1 threshold the same as max PR-AUC?": **PR-AUC is the entire curve (no threshold); τ\* is a single point on it** — and it sits at higher precision (and slightly lower recall) than the 0.5 point.

## Reading the curves

- **AFib / Sinus-Tachy (both leads):** F1 has a broad plateau and τ\* sits on the high-precision shoulder of the PR curve — moving from the orange 0.5 point up-left to the black τ\* trades a little recall for a clear precision gain, exactly the policy intent.
- **Bradycardia, fuzzy:** τ\*≈0.43 near a flat F1 peak; PR-AUC is modest (~0.58) because brady ranking is weak — the curve is low, so even the best operating point has low PPV.
- **Bradycardia, lead-II:** τ\*≈0.05 — far left. The fuzzy-trained L1 compresses lead-II brady scores, so F1 peaks at a very low threshold and the sens-floor band covers almost the whole range. This is the visual of why lead-II needs its own (low) threshold and a single global threshold can't serve both leads.
- **Threshold independence:** the PR curve and its AP are identical regardless of where τ\* is placed — only the *point* moves. PR-AUC differs between base and production solely because the score *ranking* differs (L1 vs raw head), never because of the threshold.
